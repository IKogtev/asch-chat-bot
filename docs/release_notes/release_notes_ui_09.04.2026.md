Переработана страница управления промптами, теперь она позволяет управлять агентами и их системными промптами а не только 1 агентом. Внутри редактирования промпта добавлен md редактор для удобства. Добавлно автоматическое подтягивание системного промпта в агентов, после команды /reset в телеграмм боте. Исправлены view представления для просмотра редактирования промпта, и просмотра файла новости.

Добавлена авторизация и разграничения доступа, пользователи пароли и роли задются через переменную окружения в docker-compose kb-manager: 

UI_USERS_DATA=admin:admin123:admin

- в данном случае создан пользователь admin с паролем admin123 и ролью admin
- всего две роли admin, manager
  
- маска создания  UI_USERS_DATA=user:password:role
- для создания нескольких просто перечисление через, admin:admin123:admin,manager:manager:manager
