Был произведен рефакторинг, в последствии которого бот был разбит на 5 файлов с такими функциональностями:

* bot_v6.py - основной файл ответственный за запуск работы с ботом, вызывает остальные файлы
* broadcast.py  - бекенд бота для отправки запросов от админки и получения результатов для админки kb-manager и рассылки новостей в бота
* config.py - конфиг с глобальными переменными вынесенными
* database.py - работа с базами данных для бота (Хранилище для взаимодействия с ADK API, хранилище новостей и рассылок, хранилище пользователей отправлявших сообщения боту, PostgresChatStore) 
* utils.py - вынесенные функции из bot_v6.py
* handlers.py - обработка команд к боту
