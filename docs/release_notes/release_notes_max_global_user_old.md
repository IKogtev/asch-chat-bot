# Release notes: Добавлены глобальные пользователи, общий контекст между платформами, интеграцией макс и телеграм , с защитой filegator на просмотр не авторизованных пользователей.


1. Был добавлен чат-бот для платформы макс повторяющий всю функциональность телеграм бота который был отдельным контейнером, впоследствии была произведена унификация, чтобы мы могли менять код только в 1 месте и он сразу работал на двух ботов разных реализаций.
2.  Было добавлено глобальное состояние пользователя и глобальные пользователи, теперь у нас 1 человек= 1 номер телефона глобальный пользователь, пользователь может иметь много аккаунтов, и например начать диалог на 1 платформе а продолжить на другой. 
3.  Для filegator сделана безопасность, теперь посмотреть просто файлы без авторизации нельзя, только с авторизацией.
4.  Добавлена возможность через глобальную переменную задавать интервал на время переиндексации.
5.  Группы пользователей изменены (добавлена возможность блокировки и разблокировки пользователей, теперь они отображаются там на основе глобального id, можно посмотреть id аккаунтов пользователей, нажав на кнопку id) при событии разблокировки реализовано уведомление
6.  Исправлен баг в UI с подсчетом собщений в неделю(раньше делил на 7 всегда, теперь высчитывается по умному количество недель, из выбранного промежутка)
7.  Исправлено отображение диалогов по пользователям, пользователи скачавшие документ отображаются теперь в виде таблицы
8.  Везде в диалогах добавлена платформа, чтобы понимать на какой платформе было написано  сообщение.
9.  Сделаны соответствующие alembic миграции в БД, добавлен сервис для миграций
