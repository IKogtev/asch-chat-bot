Был создан отдельный модуль в контейнере agent - smart_fallback.py реализует задачу подстановку сообщения об ошибки с детальным планом, что можно сделать пользователю. На стороне бота были реализованы fallback при потере связи с агентами. 
Реализована выдача архивных паков документов с подписью, что является архивным.
