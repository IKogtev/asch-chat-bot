## Фактические колонки классификатора

- `code` - ID продукта.
- `name` - название продукта.
- `alias` - алиас или сокращение продукта.
- `is_active` - актуальность продукта.
- `insurance_type` - тип страхования.
- `product_type` - тип продукта.
- `term ` - срок. В имени колонки есть завершающий пробел.
- `capital_loss_risk` - риск потери капитала.
- `product_risk_level` - уровень риска продукта.
- `income` - доход.
- `contribution_type` - тип взноса.
- `payout_type` - тип выплат.
- `liquidity` - ликвидность.
- `currency` - валюта.
- `fx_protection` - защита от девальвации рубля / аллокация на валюту.
- `segment` - сегмент.
- `client_goal` - цель клиента.
- `taxes` - налоги.
- `tax_benefits` - налоговые преференции.
- `commission` - КВ.
