Выполняю задачу создания чат-бот для Телеграм:
- диалог должен вестись AI-agent на базе google ADK
- должна быть возможность скачивания файлов
- будут использоваться MCP для семантического поиска документов в каталоге документации и ответа на вопросы

Какой фреймворк выбрать для создания этого чат-бота?
==========
как проинициализировать (создать) бота в Телеграм
==========
Напиши код, который:
- использует указанные в requirements.txt библиотеки
- подключается к телеграм-боту по ключу TELEGRAM_BOT_TOKEN из .env используя aiogram
- создает AI-agent с помощью google-genai, подключает к модели из .env
LLM_API_KEY
LLM_API_URL
LLM_API_MODEL
- поддерживает диалог с пользователями, сохраняя контекст
===========
Надо организовать контейнеры для БД, бота и для AI-agent, чтобы они могли взаимодействовать друг с другом. Для этого можно использовать Docker Compose заготовку "pg docker compose.yaml"
Напиши что делать по шагам для настройки и запуска этих контейнеров, а также для обеспечения их взаимодействия.
