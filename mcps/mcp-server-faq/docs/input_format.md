Введена автоматическая подготовка Markdown, происходит преобразование в нормализованный JSON, происходит поиск вопросов с помощью регулярных выражений и ответов. Добавлена поддержка ## Категория, ### Подкатегория, #### Раздел, все сохраняются в метаданных в section_path[] 

## Выходной формат после подготовки к индексации
Метаданные для индексера подготавливаются в формат:
```
"faqs": [
{
  "category": "отпуск",
  "section_path": [
    "отпуск"
  ],
  "question": "**Вопрос:** Как оформить оплачиваемый отпуск?",
  "answer": "**Ответ:** Оформление отпуска происходит через Альфа Клуб (https://alfaclub.alfastrah.ru/Pages/vacation.aspx), при формировании заявки необходимо выбрать тип отпуска \"основной\".",
  "canonical_question": "как оформить оплачиваемый отпуск",
  "canonical_answer": "оформление отпуска происходит через альфа клуб при формировании заявки необходимо выбрать тип отпуска основной",
  "source_file": "/faq_documents/FAQ_all.md",
  "source_type": "faq",
  "hash": "07a20fbaefde3db4cd904ff38e9c5e14570240515128723f91310e0673304e94"
},
{...}]
```
## pipline подготовки
Для подведения к этому формату происходит несколько операций parse_section - выявление заголовков, extract_qa - извлечение вопросов и ответов, normalize - нормализация текст и каноникализация,validate - проверка на отсутствие ошибок(пустой вопрос, ответ, слишком короткий вопрос)deduplicate - дедупликация .
```
    parse_section
        |
    extract_qa
        |
    normalize
        |
    validate
        |
    deduplicate
```
## inputs
На вход принимаются вопросы, заканчивающиеся на ? или содержащие вопросительное слово одно из: 

    "где", "когда", "почему", "зачем", "кто",
"какой", "какая", "какие",
"можно ли", "обязательно ли", "нужно ли", "стоит ли",
"возможно ли", "допустимо ли"

Ответ - сразу после вопроса, может быть 1+ строк

Заголовки ## -> Категория### -> Подкатегория#### -> Раздел

1 документ = 1 паре Question+Answer

При дублировании, на основе canonical+hash сейчас приоритет первый по порядку чтения
