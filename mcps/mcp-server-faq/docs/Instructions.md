# Инструкции и поддерживаемые форматы

На данный момент mcp сервер умеет работать с форматом файлов  `.md`
по формату
faq.md:
это как пример, а общие условия и информация указана в [input_format](input_format.md)
```
### Общие вопросы

**Вопрос:** Как работает служба доставки?
**Ответ:** Мы доставляем продукты ежедневно с 9:00 до 23:00.

**Вопрос:** Нужна ли регистрация для заказа?
**Ответ:** Нет, вы можете оформить заказ как гость.

### Оплата

**Вопрос:** Какие способы оплаты доступны?
**Ответ:** Карта, СБП и наличные при получении.
```
